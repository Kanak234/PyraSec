# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or rule bypass in `PyraSec`, please report it privately:

1. **Do NOT** open a public issue.
2. Submit a security advisory through GitHub Security Advisories or contact the repository maintainer directly.
3. Include reproducible test cases, scan payloads, and the expected vs observed findings.

Reports are acknowledged within 48 hours and prioritised for prompt remediation.
